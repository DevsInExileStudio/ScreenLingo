# Code Showcase / Snippet Library

This repository is a non-runnable code showcase. All engine structural files (.tscn, project.godot), visual assets, and core orchestrator scripts have been intentionally removed to protect intellectual property. 

The localization files (.csv, .po, etc.) and core `.gd` scripts have been preserved solely for code review, portfolio demonstration, and educational purposes. You are welcome to review the architecture and suggest improvements, but this project cannot be compiled or run in the Godot engine.
